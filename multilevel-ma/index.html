Multi-level (3-level) Meta-Analysis

When each study contributes multiple effect sizes (e.g., several outcomes, sub-scales, or time points), ignoring that dependency underestimates SEs. The 3-level model adds a study-level random effect τ²_study on top of the effect-level τ²_within.

Variance decomposition: var(θ_ij) = σ²_ij (within-effect sampling) + τ²_within (within-study heterogeneity across effect sizes) + τ²_study (between-study). Foundational 3-level MA: Konstantopoulos S. Res Synth Methods 2011;2:61–76. Implementation here: iterated method-of-moments per Cheung MWL. Psychol Methods 2014;19:211–229 — NOT REML (previous “REML-style” wording was inaccurate; this is pure MoM). For robust inference with highly clustered data, RVE is the gold standard: Hedges LV, Tipton E, Johnson MC. Res Synth Methods 2010;1:39–65 — current pooled-CI uses 1.96 z-quantile without HK adjustment, so small-cluster Type-I error is inflated; treat the report as descriptive when number-of-clusters < 10.
