Collaborate (serverless)

No backend needed: each reviewer screens locally and exchanges a small decisions file. Merging matches records by id → DOI → PMID → title, fills the other reviewer's column, and flags every disagreement as a conflict.

Or sync through one shared folder — if that folder lives inside your Google Drive / Dropbox / OneDrive folder, your desktop sync app does the upload, so there's still no account or server here. Each reviewer publishes their file; Pull & merge unions everyone's decisions. (Chrome / Edge only; on Firefox / Safari use Export / Merge above.)

Cold-start RCT classifier

Every card shows a RCT % badge — a study-design likelihood from an offline, transparent bag-of-words logistic model trained on real PubMed abstracts (labelled by Publication Type). It needs no labels from you, so it helps from record one; sort by RCT likelihood to triage trials first.

Local ML ranking

Label a few records with i/e, then train an in-browser classifier (TF-IDF + Naive Bayes, ASReview's default ranker, with class-balanced weighting) to rank the rest by predicted relevance. Retrain after each small batch for continuous active learning. 100% local, no key, reproducible.

Not trained yet.

Features: unigrams + MeSH/keywords (TF-IDF). In dual-reviewer mode both reviewers' labels train the model. Held-out AUC is 5-fold cross-validated; the stopping rule is the buscar target-recall criterion (Callaghan & Müller-Hansen 2020) — it reports the statistical confidence that 95% recall has been reached.

Conflicts to resolve (0)

Local by default — with AI assist off, records never leave your device. The optional bring-your-own-key path is the only exception: it sends the title and abstract of each screened record to the AI provider you choose (which is why connect-src allowlists those three hosts), and your key is stored only in this browser. Dedup: DOI exact + trigram-Jaccard title similarity (≥0.85), with a multi-field assist (relaxed title threshold when first-author surname AND year both match) that catches reformatted titles and same-work/different-DOI duplicates. Candidate pairs come from blocking + a sorted-neighbourhood window, so it stays fast into the 100k-record range instead of the old O(n²) pass; earliest-imported record wins. Agreement: Cohen's κ over records both reviewers decided. Effective decision in dual mode: resolved > agreement > conflict. PRISMA push writes the prisma-flow-v1 key. Relevance is a transparent term-frequency score over your own include/exclude terms — no cloud model, no black box.
