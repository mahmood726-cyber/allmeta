# Bayesian Meta-Analysis

Bayesian hierarchical random-effects meta-analysis with half-Cauchy or half-normal heterogeneity priors. Produces posterior mean, 95 % CrI, and predictive interval.

Part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.

Live: https://mahmood726-cyber.github.io/allmeta/bayesian-ma/
