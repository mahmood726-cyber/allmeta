# Approximate-Bayes NMA

Approximate Bayesian network meta-analysis via weighted-least-squares with MVN posterior. Produces SUCRAs, rank probabilities, and league tables.

Part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.

Live: https://mahmood726-cyber.github.io/allmeta/bayesian-nma/

- **Category:** Network MA
- **Data shape:** multi-arm trials in NMA shape — multiple rows per study, one per arm.
