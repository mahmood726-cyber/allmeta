Bivariate DTA / HSROC

Meta-analysis of diagnostic test accuracy: bivariate random-effects model on logit(Se) and logit(FPR = 1−Sp), with a parametric HSROC curve and summary operating point. Fitted by full maximum-likelihood bivariate random effects (Reitsma), matching R's mada::reitsma for k ≥ 4; a DerSimonian-Laird per-margin approximation is retained only as a small-sample fallback when k < 4.

Model: bivariate random-effects on logit-Se, logit-FPR, correlation ρ — Reitsma JB et al. J Clin Epidemiol 2005;58:982–990; Rutter CM, Gatsonis CA. Stat Med 2001;20:2865–2884 (HSROC). Fitted by maximum-likelihood bivariate random effects for k ≥ 4 via the shared Reitsma engine (the IGLS start and BFGS optimisation of mvmeta; parity with mada::reitsma(method = "ml") on all six mada example datasets). The prediction region is that of mada::plot.reitsma(predict = TRUE) (between-study plus estimation uncertainty). For k = 3 (or if the ML fit fails) the page shows a univariate DerSimonian-Laird per-margin approximation instead (Harbord RM et al. Biostatistics 2007;8:239–251) and says so above the results: the shared engine fits the bivariate model only for k ≥ 4, although mada::reitsma does fit k = 3 (with a warning), so those values are not mada's. SROC AUC = mada::AUC (trapezoid over FPR 0.01–0.99). Per-study CIs are exact Clopper-Pearson (= binom.test). 0.5 continuity correction when any cell is zero. HSROC curve = locus of (FPR, Se) pairs from the conditional mean linear predictor. Choosing a tool: for the Moses SROC line and a Spearman threshold-effect check (e.g. k<5 or when bivariate fails to converge), use Moses DTA-SROC →.
