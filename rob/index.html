How it works. A transparent phrase model scores each domain from Cochrane-Handbook signalling cues (e.g. "computer-generated" → low sequence-generation risk; "date of birth" → high; "opaque sealed envelopes" → low allocation-concealment risk). It returns a suggested low / some-concerns / high judgment with the sentence it matched. It never finalises a judgment — you confirm or override every domain, exactly as in the Screen app. RoB 2 verdicts use the deterministic Sterne 2019 (BMJ 366:l4898) algorithm over the signalling answers; ROBINS-I uses the Sterne 2016 domain scaffold.

Honest benchmark. Engine measured against the RoBBR gold corpus (Cochrane review authors' judgments, CC-BY-NC). On the RoBBR RobotReviewer subset (n=99, binary low vs high/unclear, Macro-F1): allmeta 62.6 vs RobotReviewer 56.7 — beats it overall and on 3 of 4 domains (loses allocation concealment 60 vs 75); still below frontier LLMs (GPT-4o 65.6, Claude Sonnet-3.5 67.5). Reproduce: node benchmark/run_rob_benchmark.mjs. All numbers [m] = measured.
