RevMan Importer (.rm5 / .rm6)

Drop a Cochrane RevMan review file (.rm5 or .rm6); this app reads the comparisons, lists each study row, and pushes the selected comparison into the shared ma-comparisons-v1 bus so any NMA / pairwise app in the suite (forest-plot, nma-pro-v2, bayesian-nma, …) can consume it without re-typing.

1. Pick a file

2. Pick a comparison

3. Send to bus

Tip: open NMA Pro v2 after pushing and click Load from bus to load the comparison.

Review metadata

Cochrane RevMan format reference: https://documentation.cochrane.org/revman-kb/revman-data-formats. Parsing supports the documented DICH_OUTCOME (binary 2×2), CONTINUOUS_OUTCOME (mean ± SD), and O_E_AND_VARIANCE (logHR / logOR) schemas. Outcomes with non-standard subgroup structures may need manual review.
