# Focus Studio

Browser-only productivity app combining a Pomodoro focus timer, a task manager, and a session tracker designed for systematic-review work sessions. Tracks focus time per task, logs completed sessions, and persists state in localStorage.

Live: https://mahmood726-cyber.github.io/allmeta/focus-studio/
