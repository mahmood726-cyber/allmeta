# p-curve + p-uniform

A browser-only tool implementing Simonsohn's p-curve (2014) and van Assen's p-uniform (2015) for publication-bias-robust effect-size estimation from sets of statistically significant p-values. The app accepts p-values via paste or CSV upload (`study`, `p` columns), filters to those strictly significant (0 &lt; p &lt; 0.05), and runs two tests: a right-skew test using Fisher's combined method (−2·Σ ln(p/0.05) ~ χ²(2k)) which detects evidential value when p-values cluster near zero, and an approximate flatness test (binomial proportion of pp ≤ 0.5) which flags curves consistent with the null or p-hacking. A p-uniform effect estimate (δ in z-units) is also computed via iterative root-finding. All computation is inline JavaScript; no server required. Results can be exported as JSON, CSV, or Markdown via the shared export module.
