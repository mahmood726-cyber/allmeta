Honest scope

Pseudo-IPD, never true IPD. AACT posts no figure and no real patient data — only summary tables. The edge over figure-digitization tools (IPDfromKM, KM-GPT) is exact registry anchors + zero digitization error + full provenance on trials with rich registry survival data — not universal superiority: a dense digitized curve carries more between-anchor shape than sparse anchors. Where the registry is sparse the engine degrades explicitly (Tier B parametric, Tier C refused) rather than fabricating. For trials with both a registry curve AND a published figure, the at-risk table is the binding constraint — see the K-M reconstructor's NAR-fusion mode.

Engine: RIPD.reconstruct vendored verbatim from the registry-ipd project (MIT; see shared/vendor/registry-ipd/NOTICE.md). Tier A picks the best of Guyot inverse-KM / censoring-informed anchor-exact / QP by minimum 1-Wasserstein to the registry anchors; Tier B is parametric with a seeded bootstrap envelope; Tier C fails closed. Provenance: registry-posted structured tables, not figure-digitized coordinates. Always verify total events / median / reported HR against the registry record before use. Everything runs on your device.
