# Thematic Synthesis

Browser-only thematic-synthesis workbench for qualitative systematic reviews. Paste participant quotes, assign each to a descriptive code, then group codes under higher-order analytical themes; results are displayed as a hierarchical tree and can be exported as JSON.

Live: https://mahmood726-cyber.github.io/allmeta/thematic-synthesis/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
