NMA Inconsistency

Detect inconsistency between direct and indirect evidence in network meta-analysis. Performs node-splitting (Dias et al. 2010) on every comparison with a closed loop, and a global design-by-treatment test (Higgins et al. 2012). Multi-arm studies are supported when all their pairwise contrasts are entered.

    Methods and Results text

    The R script refits this analysis with netmeta and metafor in native R, compares every number shown here and stops with an error on any mismatch.

    For independent two-arm studies, removing each direct comparison gives the same split as netmeta back-calculation / SIDE at a fixed shared τ². Multi-arm studies (2026-11-02): accepted and fitted as netmeta does (tol.multiarm = 0.001 on effects; graph-theoretical fit, Rücker 2012; within-study covariance implied by the contrasts); node-splits use netsplit back-calculation and the global test uses decomp.design designs (each study's full treatment set); validated against netmeta 3.6-1 to 1e-6 absolute (validate/multiarm-oracle.R, tests/multiarm-parity.mjs). RE global Q uses this consistency-model τ² as a preset; it is not the default within-design τ² test from decomp.design. Node-splitting: Dias S et al. Stat Med 2010;29:932-944. Design-by-treatment inconsistency model: Higgins JPT, Jackson D, Barrett JK et al. Res Synth Methods 2012;3:98-110. R-parity: the fixed-effect engine matches netmeta(common=TRUE) + netsplit() + decomp.design() to 1e-9 (relative; p-values 1e-9 absolute) on network estimates, per-comparison direct/indirect/diff/z/p, and the design-by-treatment Q/df/p (exact χ²; pinned replay in validate/; see hub/shared/tests/nma-inconsistency-parity.spec.mjs). Random-effects (2026-06-03): select PM or DL above to use shared τ² inflated weights (τ² from the consistency-model residuals) for both consistency and inconsistency models — addresses the prior FE-only caveat. The DL path matches netmeta(random=TRUE, method.tau="DL") τ², network estimates and netsplit() using the generalized DerSimonian-Kacker/Jackson moment denominator (see hub/shared/tests/nma-inconsistency-re-parity.spec.mjs); PM uses the generalized Paule-Mandel Q(τ²)=df moment condition (validated to 1e-6 relative against the uncentred metafor equation, p-values 1e-9 absolute). Recommended k≥5 per design.
