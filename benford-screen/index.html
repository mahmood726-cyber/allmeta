Benford screen · first-digit data integrity

Numbers that span several orders of magnitude have leading digits that follow Benford's law (1 ≈ 30%, 9 ≈ 4.6%). A large deviation can flag fabricated, altered or heavily-rounded data. This screens your values' first-digit distribution against Benford with the Nigrini MAD conformity class and a χ²(8) test — a forensic anomaly screen that complements the integrity apps (spec-collapse, INSPECT-SR, reporting-bias). It is a prompt to look, never proof of fabrication.

Caveats — when Benford does NOT apply

Benford is only valid for unbounded quantities spanning ≥2 orders of magnitude. It does not apply to bounded or narrow-range values — proportions/percentages, p-values, standardised effect sizes (SMD), I², or assigned ids — which fail Benford for legitimate reasons. Screen sample sizes, event counts, totals, costs. Need ≥100 values for reliability (≥30 minimum). A flag means "investigate" — confirm the quantity should follow Benford before reading it as a fabrication signal; conversely, conformity is not a clean bill of health.

Expected P(first digit = d) = log₁₀(1 + 1/d). Nigrini (2012) first-digit MAD classes: <0.006 close, <0.012 acceptable, <0.015 marginal, ≥0.015 nonconformity; χ²(8) goodness-of-fit (validated vs scipy). Method integrated from the BenfordMA project. Everything runs on your device.
