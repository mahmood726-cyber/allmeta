# Search Strategy Translator

Browser-only tool for translating PubMed search strategies into Embase (Emtree) and Cochrane CENTRAL syntax. Paste a PubMed query; the app maps MeSH terms, field tags, and boolean operators to their database-specific equivalents and outputs ready-to-paste translated strings.

Live: https://mahmood726-cyber.github.io/allmeta/search-translator/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
