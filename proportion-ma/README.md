# Proportion MA

Meta-analysis of single proportions using logit, double-arcsine, and Freeman-Tukey transformations with back-transformation to the probability scale.

Part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.

Live: https://mahmood726-cyber.github.io/allmeta/proportion-ma/

Binomial-normal GLMM pooling is available in the separate extras section, alongside the existing transformed-scale analysis. See [the GLMM protocol and validation scope](validate/README-plus.md) for live R fitting, explicit refusals, JSON export and the two validation tiers. The browser/native comparison retains documented cross-build failures; see the validation scope for the exact exceptions contract.
