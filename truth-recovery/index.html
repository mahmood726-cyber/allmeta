Unified Truth-Recovery Engine honest coverage

Pool a meta-analysis with a selectable engine. The classical random-effects estimators (REML / DL / PM, optionally HKSJ) run in your browser via the audited shared/ma-core.js. The Unified truth-recovery estimator (validated: ≥0.90 coverage of the true μ on all 55 known-truth cells) is Python+scikit-learn, so it runs via a local engine bridge you start once — see the status panel below.

The Unified engine returns a de-biased point and an honest-coverage interval (calibrated gated union of an amortized NPE and Manski partial-identification bounds); it also reports the partial-ID bounds and whether the gate fired (genuine selection / domain shift).
