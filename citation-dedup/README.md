# Citation Dedup

Browser-only deduplication tool for systematic review citation lists. Detects duplicates across databases using DOI matching, normalized trigram-Jaccard title similarity, first-author surname, and publication year — entirely client-side with no data leaving the browser.

Live: https://mahmood726-cyber.github.io/allmeta/citation-dedup/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
