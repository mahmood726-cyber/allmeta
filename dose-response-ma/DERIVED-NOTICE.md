# Derived-number notice: zero-case categories

The searched served corpus and rev-P02 fixtures contain no zero-case category and no matching linear slope pair. The regression dataset `constructed-zero-category-sign-reversal` is deliberately constructed, not clinical evidence and not identified as Mahmood's original data. It reproduces the reported rounded pair with linear / Hamling (`h`) / two-stage / fixed settings. One-stage fixed gives the same result.

R 4.6.0, dosresmeta 2.2.0, mixmeta 1.2.2 retain all three studies: slope -0.0463, SE 0.2886751345948129. The old engine excluded `zero-category`, producing +0.022700000000000005, SE 0.3535533905932738 from A and B. The old page parser refused the input before fitting, so the positive number is an engine/replay result, not an observed successful page result. R applies no continuity correction and emits no fit warning for this Hamling case. The app adds an informational visible retention warning.

R GL fails on raw zero cells; Hamling fails when the reference category has zero cases. Those combinations now visibly refuse the full fit, matching R, rather than return a slope on a silently reduced dataset. No covariance switching or automatic correction occurs. Independent covariance remains unchanged; the R `user` controls explicitly supply the identical 1x1 variance matrices (not arbitrary user covariance support).
