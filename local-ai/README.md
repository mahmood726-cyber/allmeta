# Local AI Setup

Step-by-step instructions for setting up a local LLM via Ollama so allmeta apps can run PICO extraction, effect-size parsing, and structured text mining entirely on your own machine — without sending any data to the cloud. Includes a live connectivity status checker and a model capability reference table.
