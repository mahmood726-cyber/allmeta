# GRADE-CERQual

Browser-only tool for rating confidence in evidence from reviews of qualitative research using the GRADE-CERQual approach. Rate four components (methodological limitations, coherence, adequacy, relevance) per review finding, and the app derives an overall confidence level (High/Moderate/Low/Very Low) with an exportable summary table.

Live: https://mahmood726-cyber.github.io/allmeta/cerqual/
