Robust Variance Estimation (RVE)

Cluster-robust sandwich estimator for meta-regression with dependent effect sizes (multiple outcomes per study, multi-arm trials, repeated measures). Implements the Hedges-Tipton-Johnson 2010 correlated-effects (CORR) working model with the CR1 small-sample correction. Coefficient SEs have correct coverage even when the within-cluster correlation ρ is misspecified — closes the inverse-variance underestimate that breaks fixed-effect / standard random-effects meta-regression when effects are nested.

Studies

When to use: any time you have ≥2 effect sizes per study (multiple endpoints, time-points, sub-scales, control comparisons), and there's no IPD to model the within-study covariance explicitly. RVE doesn't need the true covariance matrix — that's the whole point. References: Hedges, Tipton & Johnson 2010; Tipton 2015 small-sample correction; R package robumeta.

Engine: shared/rve.js — Hedges-Tipton-Johnson 2010 correlated-effects working model with CR1 small-sample correction. Knapp-Hartung-style t-quantiles via exact qt (Hill 1970). Calibration: matches robumeta::robu(model="CORR") coefficient estimates to ≤1e-6 and robust SEs to ≤5% (the residual gap is CR1 vs CR2; CR2 in clubSandwich is the more accurate but substantially heavier estimator and is roadmapped). The HIER working model is not yet implemented; for hierarchical effects use robumeta::robu(model="HIER") in R.
