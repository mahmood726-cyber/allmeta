# PICO Formulator

Browser-only PICO(T)/PECO/PICOS question builder for systematic reviews. Fill in the Population, Intervention, Comparator, Outcome (and optional Study design / Time) fields; the app generates a one-sentence review question and a boolean-search skeleton ready to paste into PubMed or the Search Translator.

Live: https://mahmood726-cyber.github.io/allmeta/pico/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
