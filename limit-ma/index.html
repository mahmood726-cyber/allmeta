Limit meta-analysis (Rücker)

Adjusts the pooled effect for small-study effects by extrapolating to the zero-variance limit via a shrunken random-effects model. Rücker et al., Stat Med 2011. R-parity: verified against metasens::limitmeta(metagen(...)).

Input

Pooled vs limit

MethodEstimateSE95% CI

Funnel + Rücker regression

Interpretation: the limit estimate is the value the random-effects model would return if all studies had zero sampling error. A large gap between the standard random-effects estimate and the limit estimate indicates small-study effects (possibly pub bias).
Rücker G, Schwarzer G, Carpenter JR, Binder H, Schumacher M. Treatment-effect estimates adjusted for small-study effects via a limit meta-analysis. Biostatistics 2011;12:122–142. Browser implementation: the full Rücker limit meta-analysis — DL τ², radial (Galbraith) regression of TE on the τ-inflated SE, limit estimate βr + τ·αr (method.adjust='beta0') with closed-form SE and the small-study/residual Q decomposition. R-parity: matches metasens::limitmeta(metagen(TE=yi, seTE=sei, method.tau='DL')) to 1e-6 on TE.adjust, seTE.adjust, αr, βr, Q.small, Q.resid and G² (tests/copas-parity-style oracle; see hub/shared/tests/limit-ma-parity.spec.mjs).
