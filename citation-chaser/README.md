# Citation Chaser

Browser-only tool for forward and backward citation chasing via the OpenAlex API. Input DOIs or titles to discover references (backward chasing) and works that cite them (forward chasing), with summary metrics and a downloadable results table.

Live: https://mahmood726-cyber.github.io/allmeta/citation-chaser/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
