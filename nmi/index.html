Network Meta-Interpolation

When effect modifiers are imbalanced across a network, a plain anchored indirect comparison is biased. NMI (Harari et al. 2023) fixes this using only published subgroup analyses: fit each study's within-study effect-modifier → treatment-effect line, interpolate every study to a common EM level, then run an anchored NMA on the balanced contrasts. Unlike MAIC it keeps the whole connected network; unlike ML-NMR it needs no individual-patient data.

Target population & model

Reduction: a single EM with two subgroup points (Independent covariance) makes each study's interpolation identical to ordinary subgroup meta-regression rma(yi, vi, mods=~x) evaluated at x*; a network with no EM variation reduces to the plain anchored (Bucher) NMA. The slope is the within-study change in treatment effect per unit of the modifier. A large spread of study populations combined with non-zero slopes is exactly the situation a plain NMA gets wrong and NMI corrects.

NMI interpolates each study's effect-modifier → treatment-effect surface (OLS) to a common target x*, reconstructs the interpolated SE, then runs an anchored NMA on the balanced contrasts. The final regression is delegated to the multi-arm-correct GLS engine shared/nma-multiarm-v1.js (verified vs netmeta to 1e−6). The single-EM two-subgroup reduction matches metafor::rma(~x) and the no-EM-variation reduction matches the Bucher indirect estimate, both to <1e−9 (live-computed anchors in tests/test_nmi.py). The reference min-norm covariance is a heuristic and does not reproduce the exact independent-subgroup SE — use it only for reference reproduction. Reference: Harari O, Soltanifar M, Cappelleri JC, et al. Network meta-interpolation: effect modification adjustment in network meta-analysis using subgroup analyses. Res Synth Methods. 2023;14(2):211–233. doi:10.1002/jrsm.1608. Computed client-side by the audited shared/nmi.js. Not a substitute for individual-patient-data methods when IPD is available.
