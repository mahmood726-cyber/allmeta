τ² via Paule-Mandel bisection; CIs use Knapp-Hartung t(k−2) with q = max(1, RSS/(k−2)) floor (HKSJ). R² measures the proportion of τ² explained by the moderator; Q_E tests residual heterogeneity (df = k−2). Export the R script to replicate with metafor::rma(yi, vi, mods=~x, method="PM", test="knha").
