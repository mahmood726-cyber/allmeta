# Local R Install

One-stop guide for installing R locally to reproduce allmeta analyses that go beyond the browser or WebR — including Stan/JAGS MCMC, large networks, and custom priors. Provides platform-specific install commands and a full CRAN package recipe covering metafor, gemtc, Stan, and JAGS.

Live: https://mahmood726-cyber.github.io/allmeta/local-install/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
