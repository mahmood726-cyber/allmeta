# Evidence Board

Browser-only structured note board for systematic-review evidence tagging. Add evidence items with source, type, and strength labels; filter and sort the board by tag or confidence level; export all notes as JSON for downstream use.

Live: https://mahmood726-cyber.github.io/allmeta/evidence-board/

Source: part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.
