E-value

How strong would an unmeasured confounder have to be — with both the exposure and the outcome — to fully explain away an observed association? The E-value answers exactly that (VanderWeele & Ding 2017), for the point estimate and for the confidence limit nearest the null. Larger E-value = more robust to unmeasured confounding.

Observed effect

Scope: the E-value is for observational estimates where residual confounding is plausible. A confidence interval is optional, but must contain the point estimate when supplied; incomplete or inconsistent intervals are refused. A missing CI never implies that the null is included. This sensitivity measure does not address selection bias, measurement error, or model misspecification.

E-value

QuantityValue

On the risk-ratio scale

E-value(RR) = RR + √(RR·(RR−1)) for RR ≥ 1 (use 1/RR for RR < 1); the CI E-value uses the confidence limit nearest the null (= 1 if that limit crosses the null). Non-RR measures are mapped to an approximate RR: OR → √OR (common) or OR (rare); HR via VanderWeele-Ding; d → exp(0.91·d) (Chinn 2000). With a standard error instead of a CI, d's limits are exp(0.91·d ∓ 1.78·SE), as in EValue's evalues.MD; a regression coefficient b is first converted to d = b·δ/SD (evalues.OLS); a risk difference uses the bias-factor method of Ding & VanderWeele (2016) with EValue's grid search (evalues.RD). Reference: VanderWeele TJ, Ding P. Sensitivity Analysis in Observational Research: Introducing the E-Value. Ann Intern Med. 2017;167(4):268-274. doi:10.7326/M16-2607. Computed client-side by the audited shared/evalue.js, verified vs the EValue R package to ~1e-6 in hub/shared/tests/evalue-parity.spec.mjs and, for the true value, SE, regression and risk-difference options, to 1e-9 in evalue/tests/test_evalue_r_parity_extended.py.
