E-value

How strong would an unmeasured confounder have to be — with both the exposure and the outcome — to fully explain away an observed association? The E-value answers exactly that (VanderWeele & Ding 2017), for the point estimate and for the confidence limit nearest the null. Larger E-value = more robust to unmeasured confounding.

Observed effect

Scope: the E-value is for observational estimates where residual confounding is plausible. It says nothing about selection bias, measurement error, or model misspecification — report it as one sensitivity input, not a verdict.

QuantityValue

On the risk-ratio scale

E-value(RR) = RR + √(RR·(RR−1)) for RR ≥ 1 (use 1/RR for RR < 1); the CI E-value uses the confidence limit nearest the null (= 1 if that limit crosses the null). Non-RR measures are mapped to an approximate RR: OR → √OR (common) or OR (rare); HR via VanderWeele-Ding; d → exp(0.91·d) (Chinn 2000). Reference: VanderWeele TJ, Ding P. Sensitivity Analysis in Observational Research: Introducing the E-Value. Ann Intern Med. 2017;167(4):268-274. doi:10.7326/M16-2607.
