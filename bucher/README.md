# Bucher Indirect Comparison

Indirect treatment comparison using the Bucher method for disconnected pairwise evidence. Reports adjusted indirect estimate with 95 % CI.

Part of the [allmeta](https://github.com/mahmood726-cyber/allmeta) collection.

Live: https://mahmood726-cyber.github.io/allmeta/bucher/

## When to use

- **Category:** Network MA
- **Data shape:** multi-arm trials in NMA shape — multiple rows per study, one per arm.
- **Purpose:** Indirect comparison (single loop).
