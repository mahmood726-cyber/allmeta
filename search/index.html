Sources: Europe PMC (resultType=core, abstracts), Crossref REST, OpenAlex (abstract reconstructed from its inverted index), ClinicalTrials.gov API v2. Expand query (free) rewrites your query with synonyms, abbreviations, brand/generic drug names and British/American spellings from a built-in dictionary — deterministic, no AI, raising recall before a single API call. The Relevance ↓ sort re-ranks results by a transparent TF-IDF cosine (unigram+bigram) against your query — a reproducible "semantic-ish" ranker, not a neural embedding. Snowball ↪ citation-chases the current results through OpenAlex (their references + citing papers) to recover work that keyword search alone misses. Cross-source dedup uses DOI-exact + trigram-Jaccard title similarity (≥0.85), deterministic source-rank survivor. Results are capped at the per-source limit you choose — totals reflect that cap, not the full database hit count. Send to Screen writes the sr-records-v1 envelope that the Screen app imports. Nothing is uploaded anywhere; API calls go straight from your browser to each public endpoint.
