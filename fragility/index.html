Fragility index — meta-analysis

How many single-patient event-status changes, added greedily across studies, would it take to flip the pooled result's statistical significance? A small fragility index means a "significant" meta-analysis hangs on very few events (Atal et al. 2019). Pooling matches metafor DL; the algorithm matches the fragility R package.

Modifications applied

    Read with care: the fragility index is a transparency metric, not a significance test. It is defined for a statistically significant pooled result (a non-significant result reports no FI here). Greedy event changes are a worst-case device — they do not represent a plausible data-generating process.
    Greedy procedure matching fragility::frag.ma(method="DL"): each step applies the single ±1 event change (across any study, either arm) that pushes the watched DerSimonian-Laird 95% CI bound furthest toward the null, stopping when significance flips. FI = number of changes; FQ = FI ÷ total sample size. Zero-cell handling follows metafor::escalc (add ½, drop double-zero studies); the DL pool delegates to the audited shared/ma-core.js. Reference: Atal I, Porcher R, Boutron I, Ravaud P. The statistical significance of meta-analyses is frequently fragile. J Clin Epidemiol. 2019;111:58-67. doi:10.1016/j.jclinepi.2019.03.012.
