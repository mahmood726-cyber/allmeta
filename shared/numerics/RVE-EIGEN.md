# R-compatible eigen kernel

`shared/rve-eigen.js` is generated by `node shared/numerics/build-rve-eigen.cjs`.
It embeds the **existing, unchanged** `libRblas.so` and `libRlapack.so` from
`r-shiny/shinylive/webr`. The build checks their SHA-256 pins, parses each
module's `dylink.0` section, asserts that its memory and table sizes fit the
loader's slots, writes the licence header and then smoke-loads the result. It
needs no network, R installation, external service or filesystem access at
runtime. The binary payloads keep their upstream licences; they are not newly
MIT-licensed code. See [LICENSES-rve-eigen.md](LICENSES-rve-eigen.md).
Upstream sources: [webR](https://github.com/r-wasm/webr),
[R BLAS/LAPACK](https://github.com/wch/r-source/tree/trunk/src/extra),
and [LLVM/Flang runtime](https://github.com/llvm/llvm-project/tree/main/flang-rt).

## Reference platform

The parity target is R 4.6.0 on **Windows x64**, robumeta 2.1 and clubSandwich
0.7.0, with **LC_COLLATE=C**. Windows x64 R accumulates `sum()` and `mean()` in
an 80-bit x87 long double (64-bit significand); `shared/rve.js` emulates that.
On R builds where long double is binary64 (for example macOS arm64) these
reductions round differently, and under a non-C collation R orders character
cluster labels differently (an English locale sorts case-insensitively), so R
itself can differ from this engine at the 1e-9 level there. Numeric cluster
IDs are ordered numerically, as `as.factor()` does for a numeric column; the
page types a cluster column as numeric exactly when R's `read.csv` would.

## Loading

The helper is activated in `shared/rve.js` together with the R-compatible
ordering, sum and mean reductions. The page loads it before the engine and
permits WebAssembly compilation in its CSP with `'wasm-unsafe-eval'`.

- In a browser the modules are compiled and instantiated **asynchronously**
  (`WebAssembly.compile` / `WebAssembly.instantiate`) as soon as the script
  runs. `AlmRVEEigen.ready` settles when that finishes and
  `AlmRVEEigen.status()` reports `loading`, `ready` or `failed`. The page
  waits for it before fitting. A CR2 eigen call made while it is loading
  throws `RVE: CR2 eigen backend is still loading…`; it never returns a number.
- In Node the modules are compiled synchronously on first use.
- If WebAssembly is absent or compilation is refused (for example by a CSP),
  every CR2 eigen call throws
  `RVE: CR2 requires WebAssembly (blocked or unavailable)`, with the original
  error as `cause`. The failure is cached; it is not retried per fit.

`hub/shared/tests/rve-meta-wasm-render.spec.mjs` fits R-referenced fixtures with
multi-row clusters through the rendered page and checks the console for CSP and
compile errors.

## Implementation

The readable implementation is `rve-eigen-runtime.js`. It implements R's
`isSymmetric.matrix` row/column prechecks and `all.equal.numeric` scaling, calls
DSYEVR or DGEEV with optimal queried workspace, orders the eigenpairs as R does,
and reproduces R's conversion to complex eigenvalues. The inverse-square-root
cutoff and reconstruction remain in the engine.

R source references (R 4.6.0, robumeta 2.1):

- `base::eigen` (`src/library/base/R/eigen.R`): symmetry dispatch, `La_rs`,
  `La_rg`.
- `base::isSymmetric.matrix`: `100 * .Machine$double.eps` and the four edge-row
  prechecks with eight times that tolerance.
- `robumeta::robu` (`R/robu.R`): eigen decomposition, cutoff at `1e-10`, and
  `V diag(d) V'` reconstruction.

The native entry points and workspace convention can also be inspected in
[R's Lapack.c](https://github.com/wch/r-source/blob/trunk/src/modules/lapack/Lapack.c).
The nonnegative reductions inside the symmetry predicate emulate the pinned
Windows R long-double sum (64 significand bits, rounding each addition). They
are local to eigen dispatch and do not change the fit's cluster means, row
ordering, or weight sums.

### Loader invariants

- Each side module gets a 16 KiB data slot and 3 table slots. The build and
  the runtime both read `dylink.0` and refuse a module whose memory size,
  alignment or table size exceeds them (libRblas: 408 bytes, table 3;
  libRlapack: 5,964 bytes, alignment 2^4, table 3).
- Function imports come from an explicit allowlist or from exports of an
  earlier module (BLAS for LAPACK). Any other import fails at link time.
  `xerbla_`, complex helpers (`cabs`, `csqrt`, `__divdc3`, `__muldc3`) and C++/
  stdio/pthread runtime calls are linked to functions that throw when called.
- `lround`/`lroundf` round halfway cases away from zero, as C does.
  `__powidf2` is compiler-rt's repeated squaring, not `Math.pow`. `logf`
  keeps binary32 conversions. `pow`, `cos`, `sin`, `atan2`, `log` and `log10`
  use `Math`.
- Three data symbols have no definition (`_ZTVSt18bad_variant_access`,
  `_ZTVSt9exception`, `stderr`). They point at a 64-byte guard block of 0xFF
  bytes, not address 0: a pointer or table index loaded from it traps, and
  any write to it is detected after the call and reported as an error.
- `__wasm_call_ctors` is not run. The DSYEVR/DGEEV paths do not need it (the
  bit-exact adjustment fixtures pass without it), and the runtime imports a
  constructor could call (`__cxa_atexit`, `pthread_mutex_init`) throw. The
  modules export no `__wasm_apply_data_relocs`.
- The shadow stack pointer is restored after every call, including calls
  that end in an exception.

The wrapper also supplies `logf` and `lroundf` for the large nonsymmetric QR
path. [LAPACK IPARMQ](https://www.netlib.org/lapack/explore-html/dd/da2/iparmq_8f_source.html)
uses `LOG(REAL(NH))` and `NINT` starting at NH = 150. The regression suite
checks all eigenvalues of a 150-by-150 tridiagonal matrix against their
analytic values, and exercises this path in the browser-global VM as well.
Kernel identity by itself is insufficient: full fits also require the matching
upstream ordering and reductions.

Run the portable kernel tests with:

```
node --test --test-isolation=none rve-meta/tests/p15-eigen-kernel.node.cjs
```

The full 16,270-configuration comparison, its captures, the residual
reference disagreements and the supplementary rho locale limitation are in the
[rve-reproducible archive](https://github.com/mahmood726-cyber/rve-reproducible).
Run `node shared/numerics/build-rve-eigen.cjs` to rebuild the bundle from the
unchanged hash-pinned repository payloads.

The CR2 `m<=p` guard follows the adjustment matrices, preserving R's complex
comparison error precedence. CR1 retains its early cluster-count guard.
The inverse-square-root cutoff remains 1e-10. The full comparison's numeric
tolerance remains 1e-9; undefined results are classified only in the audit
comparator, not in this kernel.
