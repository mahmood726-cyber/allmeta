Project Workspace

Save your whole allmeta review — every app's data and settings — as one offline JSON file, and restore it later or on another machine. Because the apps share browser storage, a project saved here carries the state of every tool you've used.

Save / load

The project file is plain JSON containing every allmeta storage entry for this browser. It never leaves your device. To move a review to another computer, save here and load the file there. After loading, (re)open the relevant apps to see the restored data.
