# GOSH validation

The live button validates CURRENT input with the self-hosted webR runner, metafor **4.8-0** (paper: **5.2-1**, R **4.6.0**, metadat **1.6-0**). No remote package requests are made. FE and DL are supported. Invalid inputs, missing evidence and R errors are refusals, never passes.

For k <= 15 it fits `rma(yi, vi, method=...)` then `metafor::gosh`, matching every exact subset membership. Above 15 it fits `rma` separately on every captured page draw, preserving its original row order and repeated memberships. Estimate, I², Q, k, DL tau² when computed, sampled SE, count, medians, extrema and type-7 estimate quartiles are checked. Live numerical tolerance is `abs(App-R)/max(1,abs(R)) <= 1e-9`, including I². Membership, count and display checks are exact. The displayed headings, labels and every summary-card value are compared with exact raw text and cardinality. The page has summary cards, not a results table.

## Declared deterministic replay subset

Replay uses **89 effect configurations / 178 FE/DL model configurations / 876,760 checks**: every k <= 12 configuration, the first two sampled configurations in the source corpus order (`dat.anand1999::001`, `dat.anand1999::002`), and all 14 over-cap configurations. Every selected configuration runs both models. Corpus and reference LF bytes are SHA-256 pinned in MANIFEST.json and the adapter. No archived app outputs stand in for current page calculations.

This is not the full paper reproduction. The full archived comparison is **12,813,556/12,813,556**, including coverage, geometry and page-cap checks. The source full browser capture took **740.561 seconds**, exceeding the approximately three-minute replay target. The deterministic subset checks engine values, summaries, exact displayed cards, sampling-control visibility, plotted counts, every default SVG coordinate and every ordered axis/tick label. Preflight schema/key/coverage assertions refuse invalid evidence; they are not added to the numerical comparison denominator. Paper/replay I² tolerance is `abs(App-R)/100 <= 1e-9`, unlike the stricter relative live check. Other statistical comparisons use the paper's relative tolerance; default SVG coordinates use absolute 1e-9. Page-cap refusals are coverage checks, not statistical agreement.

Replay restores pending input, results, plot and sampling-control state and does not write URL state or history. It works offline after preparation or by selecting the two manifest-listed files on file URLs. The shared widget and R runner are unchanged.

The companion `gosh-reproducible` archive provides `Rscript validate.R` with the paper versions. It verifies input hashes and exact coverage, refits the complete corpus, and exits nonzero on failures. Sampled fits can take hours; the historical four-worker reference runtime was 6852.135 seconds. No silent subset is used by that command. Browser rendering remains archived evidence in native R validation.

Limits: 3–100 valid input rows; FE/DL only; fixed-seed uniform-size sampler with 5,000 default draws, unlike metafor's default. Dependent rows are numerical software tests, not independent clinical evidence.

| Item | Static contract | Dynamic evidence |
|---|---|---|
| Corpus | Pinned source selection and R reference | Actual page engine and DOM replay |
| Live | Models, tolerance, pinned package binaries | Current R fits, versions and every subset comparison |
| Display | Exact headings, labels and formatting | Raw text, order and shape |

Over-cap replay checks all three em-dash values, exact labels/headings and card count, hidden sampling control (inline style and rendered visibility), empty plot and captured points, and null captured summary and export. Unexpected refusals in accepted configurations fail closed. The 28 refused model runs add 112 comparisons: 875,936 -> 876,048. Every model run (accepted or refused) also checks the model selector exactly (both option values and labels, a single selected option whose value and label match the replayed model) and that the draw control shows the requested 5,000 draws, with sampled runs also requiring 5,000 captured draws: 178 comparisons, 876,048 -> 876,226. Every model run also requires the plot error, plot omission note, sampling error and axis error messages to be empty, and the axis controls to show exactly the default axes the replay renders with (X unset, Y 0 to 100, both linear, exact labels); the user's own axis-control values are restored afterwards: 356 comparisons, 876,226 -> 876,582. Every model run also compares, exactly and in document order, every other visible text node (with its element path, so table rows, cells and containers are protected as structure, not only as reading order) and every aria-label and title in the page template (skip link, navigation, header, main content and footer, outside the validation panel: headings, the benchmark-dataset selector, control and bound labels, scale labels, thresholds, hints, buttons, interpretation and references) with the page's published text. Only the user's data and regions that have their own exact checks are excluded. Overlays that shared scripts add to the page at run time (the citation dialog and glossary tooltips) are not part of the template. The returning-user draft banner is accepted only in its exact form ("Draft from N min|h ago found. Restore?" with Restore and Discard). 178 comparisons, 876,582 -> 876,760. The live tier applies the same text check to the current page. CSV import warnings are accepted only as the importer's own messages for this page's columns. The live tier refuses (rather than fails) while the axis controls show an invalid-limits error, and reads the draw count the way the page does (so 5000.0 equals 5000).
