# Kanban Lab

Browser-only drag-and-drop Kanban board tailored for systematic-review task management. Organise review tasks across columns (e.g. Backlog, Screening, Extraction, Done), with persistent localStorage state and a clean card-based interface.

Live: https://mahmood726-cyber.github.io/allmeta/kanban-lab/
